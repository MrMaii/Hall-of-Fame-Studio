# Image Attribution

The Talent Market avatars in `src/App.jsx` use Wikimedia Commons media through
`Special:FilePath` URLs. Each avatar keeps its source file, credit, and license
label in `PANTHEON_AVATARS`; each market card links back to the matching
Commons file page.

Policy:

- Prefer public-domain or free-culture licensed Commons files.
- Keep attribution and license links visible in the UI.
- Do not use copyrighted film, comic, anime, or game stills for protected
  fictional characters. If a protected fictional character needs a visual
  avatar, use a free-licensed actor portrait and label the credit as an actor
  portrait proxy.
- For living or recently deceased people, copyright permission is separate
  from personality/publicity rights. Avoid any UI copy implying endorsement.

Current protected-character actor portrait proxies:

- Tony Stark: Robert Downey Jr. Commons portrait; no Marvel artwork.
- Light Yagami: Tatsuya Fujiwara Commons portrait; no Death Note artwork.

See the source file page for full license text, author history, and any local
reuse warnings before redistributing a modified asset bundle.
